# CodeTwin

## About
CodeTwin is a beginner-friendly Python project
that helps learners understand common programming errors.

## Features
- Identifies selected error names
- Explains possible error causes
- Provides basic debugging suggestions
- Easy-to-use command-line interface

## Technologies Used
- Python
- Git
- GitHub

## Current Version
Version 1.0 - Basic Rule-Based Error Analyzer

## Future Improvements
- Store error history using MySQL
- Build a web interface
- Add more error types
- Track common coding mistakes
